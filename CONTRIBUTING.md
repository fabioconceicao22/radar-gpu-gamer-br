# Como contribuir

1. Verifique se já existe uma issue relacionada.
2. Crie uma branch curta e descritiva.
3. Faça alterações pequenas e focadas.
4. Adicione ou atualize testes quando houver mudança de comportamento.
5. Execute `python -m unittest discover -s tests -v`.
6. Abra um pull request explicando o problema e a solução.

## Commits

Use prefixos claros: `feat:`, `fix:`, `docs:`, `test:`, `refactor:` ou `chore:`.

## Boas práticas

- Nunca inclua senhas, tokens ou dados pessoais.
- Preserve a compatibilidade dos CSVs quando possível.
- Valide domínio, URL de produto e preço antes de adicionar uma loja.
- Prefira nomes claros e funções com responsabilidade única.
